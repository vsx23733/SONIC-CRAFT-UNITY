# SONIC CRAFT UNITY

A high-speed, 2.5D Sonic-style platformer built in Unity, designed to replicate the feel of classic Sonic games with modern game development practices. This project is built for rapid iteration and extendability, perfect for level design, AI integration, and procedural generation experiments.

## Features

- Classic Sonic mechanics: dash, jump, loop-de-loops, and ring collection  
- Modular enemy AI system  
- Tile-based level system with ASCII map conversion  
- In-editor tools for custom level creation  
- Integration-ready for ML agents and procedural level generation  
- Fully integrated with Unity’s 2D rendering pipeline

## Getting Started

SONIC CRAFT is more than just a school project—it's our first step towards integrating AI into the video game industry. Whether original or not, we can’t say for sure, but it has been an exciting journey. The goal of this project, in conjunction with the initial SONIC-GAN, is to introduce automation and semi-automation into the level design and testing process for 2D platformer games, specifically Sonic-style games.

SONIC-GAN serves as a procedural level generator, creating new levels based on an initial input. Meanwhile, SONIC-CRAFT automatically reads and tests these generated levels using AI. By interpreting ASCII-encoded levels (the output of SONIC-GAN), SONIC-CRAFT dynamically generates maps in Unity and uses AI to play through these levels. During gameplay, it collects insights using AI hyperparameters to assess the quality of the levels. This allows us to improve the gaming experience based on real-time feedback and testing.

By speeding up the testing phase, SONIC-CRAFT aims to deliver significant value to game developers by saving time and to gamers by providing a more polished experience earlier in the development process. Through this innovation, SONIC-CRAFT hopes to make a unique contribution to the field of AI-driven game development.

## AI & Procedural Generation (In Progress)

With this AI, our primary goal was to develop a system that automatically tests the levels generated by SONIC-GAN (check out the repository for more details on the inspiration behind the project). This approach allows us to adjust the levels and the level-generation mode, enabling iterative improvements to the overall gaming experience.

Initially tested on hand-made 2D levels for convenience, and later applied to commercial levels, this approach is something our team aims to propose to the gaming industry as an innovative tool that AI can offer. The method we have chosen is based on reinforcement learning. Due to the dynamic nature of the project, the AI's learning environment changes as the level being tested evolves.

The ultimate goal of the AI is to reach the goal post, completing the level. The reward system is designed to reflect the core mechanics of the game, offering rewards for actions such as collecting rings, progressing forward, defeating enemies, and penalties for undesirable behaviors like moving backward or staying immobile.

While the current version of the AI isn't yet capable of completing the levels, we have reached some significant milestones in the levels that provide valuable insights, both about the AI's potential and the gameplay experience for future players.
